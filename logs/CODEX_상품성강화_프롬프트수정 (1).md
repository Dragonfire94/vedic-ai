# CODEX 지시서 — 판매형 PDF 상품성 강화 (방향 A: 프롬프트 수정)
## 토큰 절감 유지 + 고객 체감 톤 개선

**수정 대상 파일:** `backend/llm_service.py`
**수정 범위:** LLM 프롬프트 텍스트만 (코드 로직 변경 없음)

---

## 배경

현재 LLM이 출력하는 Hook/Bridge/Bullets가 "전문 리포트" 톤입니다.
- 전문용어(라그나 로드, 켄드라, 우파차야 등)가 그대로 노출
- 감정 훅 없이 정의→강점→리스크→조언 패턴 반복
- "내 이야기"보다 "점성학 설명"이 더 많음

Evidence 텍스트(시데리얼 단락)는 유지하고,
LLM이 쓰는 Hook/Bridge/Bullets 톤만 바꿉니다.

---

## 수정 1: 챕터 출력 CONTRACT 규칙 강화

`build_llm_structural_prompt` 함수(또는 챕터 출력 구조를 정의하는 프롬프트 블록)에서
아래 규칙을 찾아 교체한다.

### 현재 CONTRACT (대략 이 구조):
```
각 챕터 body는 반드시 아래 순서로만 출력:
1. Hook: 1~2문장 (공감/질문형 가능, 짧게)
2. Evidence 태그: 정확히 한 줄, 딱 1회: <EVIDENCE_BLOCK>
3. Bridge: 1~2문장
4. Action bullets: `- ` 불릿 3개
```

### 교체 후 CONTRACT:
```
각 챕터 body는 반드시 아래 순서로만 출력 (길게 쓰지 말 것):

1. Hook: 1문장만.
   - 반드시 독자가 "맞아, 나 이런 느낌 있었어"라고 고개를 끄덕일 수 있는 공감 질문 또는 감정 진술로 시작.
   - 형식 예시: "최근 ~한 느낌 있지 않으셨나요?", "~할 때 혼자만 이런가 싶었던 적 있죠?", "~한 상황이 반복되고 있다면 우연이 아닙니다."
   - 전문용어 사용 금지. 별자리/하우스/행성 이름 노출 금지.

2. Evidence 태그: 정확히 한 줄, 딱 1회: <EVIDENCE_BLOCK>

3. Bridge: 1문장만.
   - <EVIDENCE_BLOCK>에 삽입된 딱딱한 점성학 근거를 독자의 일상 언어로 부드럽게 소화해 행동으로 연결하는 역할.
   - Evidence를 다시 설명하거나 요약하지 말고, "그래서 당신에게는 이런 의미"로 바로 연결한다.
   - "이 흐름은", "이 패턴은", "이 구조는" 으로 시작해도 좋음.
   - 전문용어 사용 금지.

4. Action bullets: `- ` 불릿 3개.
   - 각 불릿은 1줄 이내.
   - 구체적 행동 + 기대 효과 포함.
   - 전문용어 사용 금지.
```

## 수정 2: 전문용어 금지 목록 추가

CONTRACT 바로 아래에 아래 금지 규칙을 추가한다.

```
[전문용어 변환 규칙 — 반드시 준수]
아래 용어는 절대 그대로 쓰지 말고, 오른쪽 표현으로 대체한다:

- 라그나 로드 / 상승궁 지배성 → "당신의 핵심 에너지", "삶을 이끄는 힘"
- 켄드라 (1,4,7,10하우스) → "삶의 주요 무대", "외부로 드러나는 영역"
- 트리코나 (1,5,9하우스) → "타고난 흐름", "자연스러운 재능의 방향"
- 우파차야 (3,6,10,11하우스) → "시간이 지날수록 강해지는 구조"
- 두스타나 (6,8,12하우스) → "반복되는 위기 패턴", "숨겨진 긴장"
- 연소(Combust) → "에너지가 눌린 상태", "잠시 빛이 가려진 시기"
- 흉성 과다 / 악성 행성 → "외부 압박이 집중되는 구조"
- 다샤 전환 → "삶의 흐름이 바뀌는 구간"
- 시데리얼 / 라히리 기준 → (Hook/Bridge/Bullets에서는 언급 금지. Evidence 단락에만 허용.)
- 아바스타 → (사용 금지)
- 요가(Yoga) → "특정 행성의 결합이 만드는 패턴" 또는 맥락에 맞게 풀어쓰기
```

## 수정 3: 챕터별 Hook 감정 키워드 힌트 추가

각 챕터 프롬프트 섹션(또는 챕터별 지시 블록)에 아래 힌트를 추가한다.
LLM이 챕터 특성에 맞는 감정 훅을 쓰도록 유도한다.

```
[챕터별 Hook 감정 힌트]
- Career & Success:
  힌트: "책임은 늘었는데 인정은 부족한 느낌", "잘하고 있는데 왜 불안한지 모르는 상태"
- Stability Metrics:
  힌트: "안정을 원하면서도 변화가 두려운 역설", "기반을 다지려 할수록 흔들리는 느낌"
- Love & Relationships:
  힌트: "가까워질수록 오히려 어색해지는 패턴", "관계에서 반복되는 같은 상처"
- Karmic Patterns:
  힌트: "분명히 알면서도 또 같은 선택을 하는 자신", "끊고 싶은데 끊기지 않는 반복"
- Health & Body Patterns:
  힌트: "머리는 괜찮다고 하는데 몸이 먼저 신호를 보내는 상황", "에너지가 갑자기 바닥나는 패턴"
- Confidence & Forecast:
  힌트: "잘 될 것 같으면서도 확신이 없는 상태", "준비는 됐는데 시작을 못 하는 느낌"
- Psychological Architecture:
  힌트: "겉으로는 괜찮아 보이지만 안에서 다른 목소리가 들리는 상태"
- Executive Summary:
  힌트: "내가 어떤 사람인지 알 것 같으면서도 모르는 느낌"
- Life Timeline Interpretation:
  힌트: "지금 이 시기가 전환점인 것 같은 막연한 감각"
```

## 수정 4: 반복 구조 금지 규칙 추가

LLM 시스템 프롬프트(또는 전체 리딩 생성 지시 상단)에 추가한다.

```
[반복 구조 금지]
- 각 챕터에서 "정의 → 강점 → 리스크 → 조언" 순서를 반복하지 않는다.
- Hook은 매 챕터마다 다른 감정/상황에서 시작한다. 같은 도입 문장 패턴 반복 금지.
- "~할 수 있다", "~가능성이 있다", "~경향이 있다" 로 끝나는 문장을 연속 2회 이상 쓰지 않는다.
- Bullets 3개가 모두 "~하라" 명령형으로 끝나는 구조 금지. 최소 1개는 질문형 또는 관찰형으로 쓴다.
```

## 수정 4-1: 설명 모드 금지 규칙 추가 ← 신규 (피드백 반영)

반복 구조 금지 규칙 바로 아래에 이어서 추가한다.
Bridge가 다시 이론 설명으로 돌아가는 것을 차단하는 가장 중요한 규칙이다.

```
[설명 모드 금지 — 반드시 준수]
- Evidence 내용을 다시 정의하거나 이론적으로 설명하지 않는다.
- "~는 ~을 의미한다", "~를 가리킨다", "~라고 본다", "~는 ~한 행성 결합이다" 형태의 설명 문장 금지.
- Evidence를 요약하지 말고, 독자의 현재 삶에 바로 연결한다.
- "이 패턴은 당신에게…", "지금 당신의 상황에서 이것은…" 형태로 적용 중심으로 쓴다.
- 점성학 이론을 가르치지 말고, 독자의 현재 상황을 해석한다.
- Hook/Bridge에서 <EVIDENCE_BLOCK>의 내용을 미리 언급하거나 복붙하지 않는다.
```

## 수정 5: Bullets 길이 압축 규칙 강화

현재 Bullets가 2~3줄씩 길게 늘어지는 경우가 있음.
ACTION BULLETS 지시 부분에 아래를 추가한다.

```
[Bullets 압축 규칙]
- 각 불릿은 40자 이내로 작성한다. (한국어 기준)
- 불릿 1개 = 행동 1개. 여러 행동을 한 불릿에 묶지 않는다.
- "~하고, ~하며, ~하십시오" 같은 나열형 불릿 금지.
- 형식: "~할 때 → ~한다" 또는 "~을 위해 ~을 먼저 한다"
```

## 적용 후 기대 변화

| 항목 | 이전 | 이후 |
|------|------|------|
| Hook 톤 | "라그나 로드의 강함과 10하우스..." | "책임은 늘었는데 인정은 부족한 느낌, 있지 않으셨나요?" |
| Bridge 톤 | "켄드라 강조는 활동성과 외부 영향력..." | "이 패턴은 당신이 드러나는 자리에 있을수록 강해집니다." |
| Bullets 길이 | 2~3줄 나열 | 1줄 단문 3개 |
| LLM 출력 토큰 | 기준값 | 10~20% 추가 절감 (Hook/Bridge 단문화) |

## 검증 체크리스트

1. `python -m py_compile backend/llm_service.py`
2. 샘플 재생성 후:
   - Hook 첫 문장에 공감 질문/감정 진술이 있는지 확인
   - "라그나 로드", "켄드라", "우파차야", "두스타나", "연소" 등 전문용어가 Hook/Bridge/Bullets에서 **0회** 등장하는지 확인
   - Evidence 단락(시데리얼 텍스트)에는 전문용어가 여전히 있어도 무방
   - Bullets 각 항목이 40자 이내인지 확인
   - 10챕터의 Hook 첫 문장이 모두 다른 감정/상황으로 시작하는지 확인
